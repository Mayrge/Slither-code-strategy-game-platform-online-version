# Snake Arena 联网版 v0.1.0

邀请码内测的多人贪吃蛇策略平台。30×30地图，500回合，自碰免死，所有蛇按最终或死亡时的冻结分数排名。与原本的“竞技台”目录独立，不共用账户、数据库或浏览器存储。

## 现在怎么用

1. 双击 **启动联网竞技台.cmd**。当前电脑已经安装依赖、创建管理员。
2. 打开 `http://127.0.0.1:3082`。管理员用户名 **Mayrge**，初始密码在 **data/管理员首次登录.txt**；首次登录后自行到“账户设置”修改密码。
3. 在“平台管理”生成邀请码：填写来源标签、人数上限及可选到期时间。将邀请码私下发给朋友，注册来源会保存。
4. 系统选手须完成真实50局初始定榜。当前电脑已完成这轮比赛；新安装可点击“系统选手初始定榜”。
5. 朋友登录后在“策略”保存草稿，选择品牌、模型及颜色，上传JavaScript代码。草稿可练习；注册选手才能排位。

初次安装到另一台电脑，需要 Node.js **24.4或更新版本**，先双击 **首次初始化.cmd**。首次安装需要联网下载解释器依赖；运行时不调用任何AI接口，也不要求AI服务密钥。

## 已实现

- 首页三层永续联赛：华山论剑、凌云争锋、潜龙试剑；最高联赛前三突出展示。
- 每账户最多5名同时未退役选手；滚动12小时最多注册5名；名称、模型、代码注册后固定。退役永久，保留历史。完全相同的代码不可在同账户换名注册。
- 管理员提供的品牌/模型必选菜单，包括品牌内“不知道”、自己独立完成、多模型及必填的其他说明；可随时增删，已注册选手保留原标签。
- 系统排位固定50局，执行时按最新榜单匹配，每普通账户最多一名选手。完整结算自动入榜，每选手独立冷却12小时。初次定位可以直接第一，不累计刷局数加分。
- 单局可视化练习、1～100局自由赛程、筛选回放、逐回合/倍速播放、自己选手最佳/最差及三个随机回看。自由赛程不参与排名。
- 删除赛程同步删除回放；已结算排名与历史记录不回滚。
- 普通账户仅能获取自己的策略。管理员可审核所有策略，管理邀请码、账户、模型，删除留言；操作留记录。用户注册须知此权限。
- 独立交流留言栏，所有登录账户可见。文本最多500字，发送间隔30秒；作者和管理员可删除。
- 一键复制竞技提示词，一键下载AI训练包；空地图、独立裁判、自己提供对手、逐回合JSON记录，包内仅提供琥珀·拾荒作为基础练习对手，不含其他系统策略。

## 数据和版本分别保存

源代码、规则、测试、版本号可以上传GitHub。**data/** 中的账户、邀请码、用户策略、比赛数据库、密码文件和数据备份，**.env** 中的线上地址配置均被Git忽略；不要手动上传这些文件。

双击 **备份比赛数据.cmd**，会生成一致的SQLite快照，存入 **data/backups/**。可在服务运行时备份。恢复时先停止竞技台，将选定快照复制为 `data/arena.sqlite`；旧数据库及对应 `arena.sqlite-wal`、`arena.sqlite-shm` 应先移到私人备份位置，避免混用。GitHub源代码备份不等于账户与比赛数据备份。

## 给朋友开放

请阅读 [联网部署说明.md](联网部署说明.md)。网站在笔记本执行，Cloudflare Tunnel提供入口，不需要把整个项目上传到Cloudflare。电脑休眠、关机、断网时网站不可访问。当前版本适合少量受邀朋友内测，比赛串行执行，有队列等待。

## 开发与验证

```sh
npm ci --ignore-scripts
npm run setup
npm start
npm test
npm run kit
```

不要对已有管理员重复执行setup；不会覆盖原账户。Node自身读取可选的`.env`。服务仅监听127.0.0.1，不对局域网直接开放。发布新版本修改package.json、界面和CHANGELOG，测试后提交并打同名Git标签。

策略在QuickJS的WebAssembly解释器中执行，不暴露文件、网络、Node、宿主回调；每个选手16 MiB内存、50毫秒接受结果预算。初始化和比赛在独立工作线程，另有无响应终止及并发/频率限制。内存回收可能超过接受预算，但超时结果不被采纳。本版本尚未做独立安全审计或大规模并发压测。

如果GitHub仓库公开，仓库里的系统选手源码也会公开；用户策略和私有运行资料不在源码仓库中。普通账户无法读取他人策略；资料包仅公开琥珀·拾荒这一份系统策略。
